Planned functional changes

What customers and users will see change over the next two weeks, across the web platform and the mobile app. Team: two web developers and one mobile developer.

29 July 2026

Web platform

The referral feature is the largest item of the two weeks; the rest of the web work is sized around it.

Referral registration Web

An approved company gets a link they can share. Companies they refer register through that link and start using Wergonic immediately, with no manual approval step from us.

Graphs and full time series open by default Web

Users currently have to expand them manually every time they open a report. Small change, immediately noticeable.

Correct the "Measured this month" figure Web

The Workers page always shows zero today, so customers are looking at a number we know is wrong.

Demo organization Web

A ready-made company for showing the product to prospects. It comes preloaded with the setup data — activities, conditions, profiles and similar.

It will not come with ready-made risk assessments or measurements. Our testing is focused on whether new measurements and assessments are created correctly, which tells us far more than reviewing pre-made ones that already show sensible numbers. Instead we will add a script that cleans the demo organization periodically so it never fills up.

Session cleanup Web

Clear the junk and test sessions out of production so demos and customer views show real data.

Mobile app

Quick start reuses the last calibration Mobile

Skip calibration when we already have valid data from the previous session, with a warning to re-calibrate if the sensors or the t-shirt have moved. This removes the slowest step of starting a measurement.

Clearer sensor combination message Mobile

Today the app says the combination is impossible. It needs to say plainly that both the forearm and hand sensors are required.

Default condition sets Mobile

Ready-made General and Industrial conditions, so a new customer does not start from an empty list.

Updated manual with screenshots Mobile

Including what actually happens when a sensor loses connection and how long we keep retrying, which customers keep asking about.
